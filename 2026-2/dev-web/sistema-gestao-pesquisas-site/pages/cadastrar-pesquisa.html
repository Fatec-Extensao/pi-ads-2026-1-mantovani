Cadastrar Nova Pesquisa (US-ADM-01)

Sobre esta funcionalidade

Como Administrador, quero cadastrar uma nova pesquisa informando título, descrição e período, para iniciar o ciclo de vida de uma pesquisa institucional.

Ao salvar, o sistema valida os campos obrigatórios, persiste a pesquisa com status inicial "Rascunho" e registra a operação na trilha de auditoria.

Formulário de Cadastro

Dados da pesquisa



Entre 5 e 100 caracteres.



Descreva o objetivo e o público-alvo da pesquisa.




A data de fim deve ser posterior à data de início.

Status inicial

Fluxo Alternativo — Período Inválido

Se a data de fim for anterior à data de início (ou retroativa), o sistema interrompe o salvamento e exibe: Data fim deve ser posterior à data início. Os campos preenchidos são mantidos na tela para correção.
