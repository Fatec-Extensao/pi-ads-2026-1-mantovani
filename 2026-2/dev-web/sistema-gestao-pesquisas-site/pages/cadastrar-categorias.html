Cadastrar Categorias de Participantes (US-ADM-02)

Sobre esta funcionalidade

Como Administrador, quero cadastrar categorias (ex.: Alunos, Professores, Colaboradores), para segmentar o público-alvo de cada pesquisa. Cada pesquisa pode possuir uma ou mais categorias de participantes.

Formulário de Cadastro

Nova categoria




Máximo de 50 caracteres. O nome deve ser único (não diferencia maiúsculas/minúsculas).
